# Global Layoffs Data Analysis

This project focuses on cleaning, standardizing, and analyzing a real-world global layoffs dataset.

## Dataset
Source: Kaggle – Global Layoffs Dataset

## Data Cleaning (SQL)
- Created staging tables to preserve raw data
- Removed duplicate records using window functions
- Standardized categorical fields (industry, country)
- Handled missing values using self-joins
- Converted string-based dates to DATE format

## Exploratory Data Analysis (EDA)
- Analyzed layoffs by industry, country, and company
- Identified time-based trends in layoffs
- Performed aggregations to extract insights

## Tools Used
- MySQL
- SQL
- (Optional) Python, Pandas, Matplotlib
